# 更新日志 / Changelog

## v1.0.2 — 2026-09-16（多人模式降费状态越界修复）

> 本次更新**修复多人联机下的严重 Bug**，机制与数值不变。

### 修复（重要）
- **咆哮（能力·金）**：原实现 `TryModifyEnergyCostInCombat` 未限定卡牌拥有者，
  多人模式下会误把「其他玩家」的攻击牌也减 1 费，且各客户端算出的扣费不一致，导致**数据不同步**。
  现限定仅对本体的攻击牌生效（卡牌拥有者 == 状态拥有者）。
- **立牧（技能·蓝）**：其附属状态 `LiMuZeroCostPower`（`TryModifyEnergyCostInCombatLate`，
  本回合攻击牌消耗为 0）存在**同一越界问题**，本次一并修复，避免多人模式下把所有人攻击牌压到 0 并引发同步错误。

### 影响范围
- 单人模式行为不变（本体攻击牌降费照旧）。
- 仅改动 `PaoXiaoPower.cs` 与 `LiMuZeroCostPower.cs` 两个状态的降费判定，未触动任何卡面数值、品质与描述。
